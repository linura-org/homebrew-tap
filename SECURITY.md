# Security Policy

This repository contains distribution metadata for Linura. The authoritative Linura security policy lives in the main repository:

https://github.com/linura-org/linura/blob/main/SECURITY.md

Do not open a public issue, pull request, Discussion, or chat thread for a suspected vulnerability.

Use GitHub private vulnerability reporting in the main `linura-org/linura` repository, or email **security@linura.org**.

Homebrew packaging must not weaken Linura's release, provenance, checksum, privilege, or verification boundaries. A packaging-only change that alters source origin, artifact verification, install/update behavior, privileges, or executable contents should be treated as security-sensitive.
